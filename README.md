# 32146 assessment materials

This repository keeps the two assessment deliverables separate.

- `32146-at1/` contains the Pacific Smiles Group (PSQ) stock-analysis work: source
  data, generated workbooks and charts, report material, analysis scripts, and
  backtest scripts.
- `at2/` contains the Wimbledon assessment source workbook, its processing and
  report-building scripts, final outputs, and temporary render artefacts.

Run AT1 scripts from their own directory or by file path; they resolve data and
report locations relative to `32146-at1/`. The AT2 build scripts resolve all inputs
and outputs relative to `at2/`.
